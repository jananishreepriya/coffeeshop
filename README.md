☕ CoffeeShop – Flutter Web App

A minimalist coffee shop interface built using Flutter for Web. This project was developed during my self-learning phase to explore Flutter.

🔗 Live Demo: https://coffeshopapp.netlify.app

Features
- Home screen with coffee menu
- Coffee items with name, price, and icons
- Add-to-cart simulation using "+" buttons
- Footer button ("Shop") with lock icon for future login/cart integration

Tech Stack
- Frontend: Flutter (Dart)
- Deployment: Netlify
